# 校园网守护 · Glass 界面版

## 开始使用

1. 从托盘退出旧版网络守护，避免两个实例同时监控。
2. 将运行包解压到长期保留的文件夹，运行 SZU-Guardian-Glass.exe。
3. 程序沿用原配置目录和 Windows DPAPI 密码存储。若已有配置，会读取原有设置；没有则在“状态”页填写账号、密码、实际网络区域和检测间隔。
4. 保持“检测与认证强制直连”开启。FlClash 可以保持原状。
5. 点击“保存设置”，然后“开始守护”。正在守护时修改连接设置，需要暂停后重新开始。
6. UU 完整重启继续使用 Claude 版的授权任务及重启流程。已授权的机器无需重新授权；未授权时点击“授权完整重启”并完成 Windows 提示。
7. 手动重启 UU 前先暂停守护，避免与自动重连同时操作。重启会中断已有远程会话。

## 外观

- 使用所选蓝色连接环作为 EXE、窗口和系统托盘图标。
- 状态、设置、记录三页；主题颜色只出现在“设置”页。
- 雾霾蓝、薄荷绿、浅薰衣草、蜜桃粉、奶油杏五种预设。
- 点击颜色即时预览，也可输入 #RRGGBB 或打开颜色选择器。点击“保存外观”后下次启动继续使用。
- 外观单独保存在原配置目录中的 appearance.json，不要求重新输入账号，不改变密码存储。
- 状态页显示“下次检测将在 X 分钟内进行”，等待期间按剩余分钟更新；暂停后清除倒计时。
- 采用本地绘制的柔和渐变及半透明卡片呈现玻璃质感，不依赖桌面壁纸或系统透明效果。
- 小窗口可以滚动；关闭或最小化后留在托盘，通过托盘或窗口内“退出”真正结束。

## 代码来源与验证范围

以用户提供的 Claude 项目快照为基础，界面由 Tk 改为 Qt。
network.py、monitor.py、uu_remote.py、srun.py、direct_network.py、storage.py、models.py、startup.py 共 8 个业务模块保持与取用快照相同，SHA-256 基线见 backend-baseline.json。
Qt 界面创建后清理打包环境中的 Qt 插件目录及 PATH 注入项，防止外部 UU 进程继承新界面的 Qt 环境；UU 重启模块本身未修改。
自动重连及 UU 触发条件沿用 Claude 版本，包括网络稍后恢复时触发重启。
界面截图使用虚构演示数据，不表示已经在当前校园网完成登录。
本次没有主动注销校园网、停止真实 UU 或更改机器上的自启、授权任务。

## 从源码构建

Windows x64，Python 3.10+（本次构建使用 Python 3.14.8）。运行 build.ps1；依赖版本见 requirements-lock.txt。
构建脚本运行 unittest 后打包单文件 Windows GUI 程序。
源码包中的 licenses/ 附有 LGPL/GPL 许可原文；项目原 MIT 许可和第三方说明保留。
Qt/PySide6/Shiboken 使用开源发行包，源代码地址见 COMPONENTS.md。
